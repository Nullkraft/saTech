Protocol direction
------------------

Separate transport encoding from payload state.

Transport encoding:

- ASCII: receive a complete token or line, convert it to the shared uint32_t
  word format, then process it.
- Binary: collect exactly 4 bytes, convert them to one little-endian uint32_t
  word, then process it.

Payload state:

- Command.
- FMN data.
- Direct register data.

Runtime processing should be:

1. Read one complete uint32_t word through the selected transport codec.
2. Classify/process that word through the payload state machine.
3. Keep ASCII-vs-binary handling out of normal command/data processing.

  saTech.begin("ascii").
- Progress: setup code can precheck serial tokens with
  saTech.supportsEncoding(token) before calling saTech.begin(token).
- The library API should provide saTech.begin(...) for ascii and binary,
  accepting capitalization variants.
- Unsupported encoding strings should be ignored.
- The sketch setup() is responsible for choosing or waiting for the encoding
  before runtime starts.
- If setup waits for a serial token, it should keep waiting until ascii or
  binary is received. A periodic reminder string is acceptable.
- Encoding selection is configuration, not part of the runtime payload state
  machine.

Word formats
------------

- Wire byte order: little-endian 32-bit words.
- FMN packed data: F=[31 downto 20], M=[19 downto 8], N=[7 downto 0].
- FMN N will never equal 0xFF.
- Direct register data: 32-bit register word; register address lives in
  Addr=[2 downto 0].
- Direct register data LS byte will never equal 0xFF.
- Command/control data: data=[31 downto 16], command=[15 downto 11],
  address=[10 downto 8], command_flag=[7 downto 0].
- Command flag is always 0xFF.
- Command data bits are currently unused but must remain accounted for.

Mode command words
------------------

- Enter command: 0x000006FF.
- Enter FMN data: 0x00000EFF.
- Enter direct register data: 0x000016FF.

State-transition rules
----------------------

- In any payload mode, a completed word with LS byte 0xFF is a command word.
- In FMN data mode, completed non-command words are FMN data.
- In direct register mode, completed non-command words are register data.
- From FMN data mode, switch modes only through a command word.
- From direct register mode, switch modes only through a command word.
- From command mode, allow switching to FMN data or direct register mode.
- From command mode, allow switching between ASCII and binary transport
  encoding.
