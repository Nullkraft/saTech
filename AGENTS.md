## Agent delegation
- Any mention of "someone", or similar wording, indicates an agent should be requested.
- When agents are involved, have them update `LIBRARY_API.md` and `Transition notes tomorrow handoff.txt` as progress is made.

## Repository ownership
- The user is the only person making changes to the local and remote repositories.
- Use simple `git add`, `git commit`, and `git push` commands when committing or pushing.

## File scope exceptions
- `LIBRARY_API.md` and `Transition notes tomorrow handoff.txt` do not count against the 1-file update restriction.
